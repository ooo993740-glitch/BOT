# بوت ناصر 🦅 — دليل النشر (من التلفون)

## 1️⃣ إنشاء البوت في تيليغرام
1. افتح محادثة مع **@BotFather**
2. اكتب `/newbot` واتبع الخطوات (اسم، يوزرنيم ينتهي بـ Bot)
3. يعطيك **توكن** (شكله: `123456:ABC-xyz...`) — احفظه

## 2️⃣ إعداد Firebase
1. روح لـ [console.firebase.google.com](https://console.firebase.google.com) وافتح مشروعك (نفس واحد NASR ولا جديد)
2. فعل **Firestore Database** إذا ماشي مفعل (Build → Firestore Database → Create)
3. روح لـ ⚙️ Project Settings → Service Accounts → **Generate new private key**
4. يحملك ملف JSON — افتحو وانسخ **كامل المحتوى**

## 3️⃣ رفع الكود على GitHub
1. حمل تطبيق **GitHub** من المتجر، ولا استعمل موقعهم من المتصفح
2. أنشئ مستودع (Repository) جديد، سميه `nasr-bot`
3. ارفع كل الملفات اللي عطيتك (index.js, ranks.js, ...) — تقدر ترفعهم واحد واحد من واجهة GitHub بالتلفون (زر "Add file" → "Upload files")
4. **لا ترفعش** ملف `.env` ولا `serviceAccountKey.json` (فيهم أسرار)

## 4️⃣ النشر على Render
1. سجل في [render.com](https://render.com) (تقدر بحساب GitHub)
2. New → **Web Service** → اختار مستودع `nasr-bot`
3. الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Plan: **Starter** (7$/شهر) — باش يبقى شغال 24/24
4. تحت **Environment**, ضيف المتغيرات هاذو (من `.env.example`):
   - `BOT_TOKEN` → التوكن ديال BotFather
   - `BOT_USERNAME` → يوزرنيم البوت بلا @
   - `OWNER_ID` → آيدي تيليغرام ديالك (احصل عليه من @userinfobot)
   - `FIREBASE_SERVICE_ACCOUNT` → الصق كامل محتوى ملف JSON اللي حملتو في خطوة 2
5. اضغط **Create Web Service** — Render يبني وينشر تلقائيا (ياخذ 2-5 دقايق)

## 5️⃣ التجربة
1. افتح البوت في تيليغرام، اكتب `/start` — خاص يرد بالرسالة الترحيبية
2. ضيفو لقروب تجريبي، رفعو **أدمن** (Admin) بكل الصلاحيات
3. جرب: `كتم` بالرد على رسالة، `رفع ادمن` بالرد على شخص، `يوت اسم أغنية`

## 6️⃣ إعداد الاشتراك الإجباري (أنت المالك برك)
1. افتح خاص مع البوت (بدون قروب)
2. اكتب: `اضف قناة @اسم_قناتك`
3. **مهم:** خاص البوت "ناصر" يكون أدمن في القناة هاذي باش يقدر يتحقق من الاشتراك
4. تقدر تضيف أكثر من قناة بنفس الطريقة — العضو خاصو يشترك في الكل

## ⚠️ ملاحظات مهمة
- خاصية `يوت` (تحميل يوتيوب) تخالف شروط استخدام يوتيوب، استعملها بحذر — ممكن تسبب مشاكل مع الحساب إذا استعملت بكثرة
- إذا بديت البوت وما خدمش، تحقق من **Logs** في Render (يبين الخطأ بالضبط)
